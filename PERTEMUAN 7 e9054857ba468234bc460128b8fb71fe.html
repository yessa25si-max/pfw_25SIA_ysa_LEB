📂 CRUD User

Sekarang kita akan buat fitur CRUD untuk data User dengan form berikut:

  • Name → name=”name"
  • Email → name=”email"
  • Password → name=”password"
  • Confirm Password → name=”password_confirmation"

Langkah 1 - CRUD

  1. Migration dan Model tidak dibutuhkan, karena sudah tersedia
    • Pada model User , $fillable juga sudah berisi name, email , dan password

  1. Buat resource controller dengan nama UserController

    Kalian bisa copy-paste dari Pelanggan Controller untuk setiap isi dari function index(), edit(), store() , update() dan destroy(), namun tetap disesuaikan pemanggilan Model dan data yang akan di-inputkan

    • function index() → terapkan User::all() dan tampilkan view admin.user.index
    • function create() → tampilkan view admin.user.create
      • Gunakan Hash::make() untuk menyimpan password terenkripsi.

    • function edit() → terapkan User::findOrFail($id) dan tampilkan view admin.user.edit
    • function store() → seperti milik Pelanggan namun sesuaikan data yang akan disimpan dan terapkan User::create($data)
    • function destroy() → seperti milik Pelanggan namun sesuaikan menjadi $user→delete()

  1. Buat direktori baru di admin/user , lalu pada folder user silahkan buat halaman index.blade.php, create.blade.php dan edit.blade.php

    Karena kita sudah menerapkan Partial View pada menu Pelanggan, kali ini kita hanya cukup copy-paste isi dari index, create dan edit milik pelanggan ke user dan sesuaikan Form beserta inputan-nya seperti berikut

  1. Tambahkan <li> untuk menu User di layouts/sidebar.blade.php

Langkah 2 - Validasi

Jika CRUD sudah berhasil, lanjutkan dengan aksi berikut:

  1. Terapkan validasi pada form berupa :
    • name → required, string, max:100
    • email → required, email, unique:users,email
    • password → required saat create, min:8, confirmed

      Untuk confirmed , pastikan name pada inputan Confirm Password adalah password_confirmation

  1. Pastikan form bisa repopulate setelah error (old()).
  1. Tampilkan flash data untuk success/error baik di create.blade.php maupun edit.blade.php
